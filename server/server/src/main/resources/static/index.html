01 / 沟通

把事情说明白

私聊与群聊支持富文本、图片、语音、视频和文件。回复、转发、编辑与撤回，让沟通保持连贯。

  • 群成员与角色管理
  • 邀请链接与剪贴板入群入口
  • 消息搜索与多设备同步
02 / 资料

让知识有归处

按空间组织团队文档，用 Markdown 编写正文。文档树、全文搜索与评论，让资料易于维护和查找。

  • 空间权限与文档分享
  • 版本历史与恢复
  • 桌面多标签与独立窗口
03 / 跟进

让待办看得见

在群里显示未完成的共享待办，为执行人保留提醒横幅。描述、文档和附件一起交代清楚任务。

  • 每周、双周或每 N 月重复
  • 开始时间、截止时间与提醒
  • 延期理由、次数与处理耗时

你的团队，

TeamTalk 将客户端、服务端、协议和部署工具放在同一个开源仓库。面向单组织与中小型团队，便于私有部署、维护和二次开发。

不需要技术背景：把仓库交给 WorkBuddy 等 AI 助手，它会阅读仓库内的部署指南，替你完成搭建——大陆访问 GitHub 困难时，AI 可以通过镜像拉取代码。
