# 设计系统

TeamTalk 使用偏中性、信息密度适中的办公产品语言。视觉参考飞书的层级和紧凑度，但组件与交互由
自身产品结构决定。代码权威位置是 `app/.../ui/theme/Tokens.kt` 与 `AppTheme.kt`。

## 1. 设计原则

1. **层级来自表面和留白，不来自厚重阴影。** 导航、列表和内容使用不同中性色面。
2. **品牌色用于动作和状态。** 大面积消息气泡使用浅色容器，避免高饱和蓝压迫正文。
3. **桌面紧凑、移动可触。** 共享语义令牌，平台尺寸分别定义。
4. **空态解释下一步。** 不使用 logo 或演示数据占据无意义空间。
5. **状态完整。** 默认、hover、selected、disabled、loading、error 和 focus 必须可区分。

## 2. 语义颜色

| 令牌 | 亮色 | 用途 |
|---|---|---|
| `primary` | `#3370FF` | 主动作、链接、焦点 |
| `background` | `#F5F6FA` | 应用底色 |
| `surface` | `#FFFFFF` | 内容与卡片 |
| `surfaceVariant` | `#F0F1F5` | 列表与低层级表面 |
| `hover` | `#EDEEF1` | 桌面悬停 |
| `selected` | `#E1EAFF` | 选中列表项 |
| `divider` | `#E5E6EB` | 1px 分隔 |
| `bubbleIncoming` | `#F2F3F5` | 对方消息 |
| `bubbleOutgoing` | `#E8F0FF` | 自己消息 |
| `secondaryText` | `#646A73` | 副标题与预览 |
| `metaText` | `#676D76` | 时间、占位和系统提示（小字可读对比度） |
| `online` | `#34C724` | 在线状态 |
| `unreadBadge` | `#F54A45` | 未读与危险提醒 |

暗色使用 `#16181D` 背景、`#1D2026` 表面与 `#5B8DFF` 主色。任何新增颜色应先定义语义，而不是
在组件里硬编码“更好看”的值。

## 3. 字阶与栅格

| 样式 | 规格 | 用途 |
|---|---|---|
| `titleMedium` | 16 / SemiBold / 24 | 面板标题 |
| `titleSmall` | 14 / Medium / 20 | 会话、联系人和卡片标题 |
| `bodyMedium` | 14 / Regular / 20 | 正文与输入 |
| `bodySmall` | 13 / Regular / 18 | 预览与副标题 |
| `labelMedium` | 12 / Medium / 16 | 按钮与徽标 |
| `labelSmall` | 11 / Regular / 14 | 时间和系统信息 |

间距遵循 4dp 栅格：`xs=4`、`sm=8`、`md=12`、`lg=16`、`xl=20`、`xxl=24`。

## 5. 形状

- 头像是圆角方形，圆角约尺寸的 22%，不是圆形。
- 输入框、气泡和普通卡片以 8dp 为主。
- 模态与大卡片使用 12dp。
- 徽标和短状态使用 pill。
- 消息气泡不用夸张尾巴；靠头像一角可收至 4dp 表示方向。

## 6. 关键组件

### 会话项

40dp 头像 + 两行文本；名称、时间、图钉与未读在首行，预览或红色草稿在第二行。右键/长按提供
置顶和标记已读，不把每个低频动作做成常驻按钮。

“保存的消息”首次收藏前不显示（空的私有会话也不占位）；有内容后复用普通会话行，显示最近内容、
时间、选中态和书签角标，按用户置顶状态及最后消息时间排序。它不作为列表外的固定首项；用户可以
像普通会话一样置顶、取消置顶、免打扰和标记已读。列表没有可见会话时显示“暂无会话”。

### 消息气泡

双方都保留头像作为对齐锚。短文本按内容收缩；代码块和媒体才使用最大宽。连续消息隐藏重复头像
但保留头像占位，组间距大于组内距。

图片和视频使用同一比例的 fit-inside 预览，不为满足最小边长而二次放大或裁掉内容。Markdown 内嵌
资产按正文顺序纵向排布，图片与文件卡之间保留 8dp 间距；文件卡自身承担边框、内边距和点击面。
极端宽高比仍保持内容 Fit，但预览表面至少保留 48dp 的交互短边，防止点击和长按区域塌缩。

### 聊天编辑器

编辑器按可用宽度响应，而不是按平台复制两套交互：`<560dp` 使用紧凑布局，默认只占一行输入和一行
核心动作；低频格式按需展开。`>=560dp` 保留完整格式栏与文字发送按钮。表情、附件和更多格式面板互斥，
打开新面板必须关闭旧面板，避免在移动端堆叠占据消息视区。

### 文件卡片

扩展名色块、最多两行文件名、大小和下载状态。小文件静默下载，大文件等待点击；进度必须有动画，
错误可重试。

### 空态

图标、主提示和一行解释居中，描述用户下一步。会话、通讯录、设置、搜索无结果和底层能力缺失
使用不同文案。

## 7. 动效

动效只解释状态变化：检查器滑入、下载进度、播放状态和弹层出现。hover/selected 应即时响应，列表
不添加装饰性位移动画。所有动效尊重平台减少动态效果设置。
