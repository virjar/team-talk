# 后端缺失占位清单（视觉先行，接口后补）

> 原则：**UI 按完整产品形态设计，数据没到位就留空/隐藏，不硬造**。
> 每项标注三态：`✅ 可接`（数据已在 wire/SDK，纯 UI 工作）｜`🟡 半接`（部分链路在）｜`🔴 缺口`（需补后端）。
> 后端补齐后在本表勾销并更新组件实现。

## 清单

## 本轮直接落地的（不属占位）

- 会话项时间戳/静音图标/选中态/hover 态/右键菜单（含标记已读——本地水位线）
- 气泡双方头像/指向角/裸文字时间分隔/带主语撤回文案
- Enter 换行、Cmd/Ctrl+Enter 发送、工具行左对齐、空态升级
- 细导航栏（56dp 图标式）

## 后端补齐的推荐顺序（按 UI 价值/成本）

1. **presence 快照 RPC**（#2）：一个 `PresenceRpc.batchQuery(uids)` + 登录后拉取，聊天/通讯录立刻"活"起来
2. **updateProfile 支持 avatar**（#1）：字段已在，改动最小
3. **typing NOTIFY**（#4）：契约表加一行，客户端 3s 防抖
4. reaction（#6）：新表 + NOTIFY + 拉取合并，工作量最大，放最后
