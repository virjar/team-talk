# 组件与页面规格

> 本文定义每个 UI 组件的结构、状态与交互。实现文件以 `app/src/commonMain/kotlin/com/virjar/tk/ui/` 为根。

## 1. 核心组件

### 1.1 头像 `AvatarPlaceholder` / `ChatAvatar`

- **圆角方形**（squircle，圆角 = 尺寸 × 0.22），非圆形——飞书强识别特征。
- 内容：首字符（跳过 emoji，取首个字母/数字/CJK，fallback `?`）+ 名称哈希色底 + 白字。
- 群聊角标：仅 `ChatAvatar`，右下角 45% 尺寸圆底白框 + Groups 图标（群成员≥2 的视觉暗示）。
- 预留：`url` 参数（真实头像，当前忽略，见 placeholders.md §1）。
- 在线状态点（预留）：右下 10dp 绿点 + 2dp 白描边，数据未接入前不渲染。

```
┌────────────┐
│ 张    ╭──╮ │      40dp，圆角 8.8dp
│ (蓝底)│群│ │      群角标仅 ChatAvatar
│       ╰──╯ │
└────────────┘
```

### 1.2 会话列表项 `ConversationItem`

两行结构，高度 64dp（内容盒），左右 padding 12dp：

```
┌──────────────────────────────────────────────┐
│ [头像40]  张三                    📌 14:32  ② │  ← 行1：名称(14 Medium) + 置顶图钉 + 时间 + 未读徽标
│          你好，明天见…                          │  ← 行2：预览(13, metaText)/草稿(红, "[草稿] "前缀)
└──────────────────────────────────────────────┘
  hover:    背景 Tk.colors.hover
  selected: 背景 Tk.colors.selected（时间/预览不换色）
  普通态:   透明背景
```

- 未读徽标：`unreadBadge` 色 pill，`99+` 封顶，右侧垂直居中于行1。
- 置顶：小图钉（16dp，`pinIcon` 灰）跟在时间左侧，**不再是每行一个 IconButton**。
- 置顶会话区：置顶项整体加 `#F7F8FA` 底（亮色）作为分区暗示（与微信一致，飞书无此层——我们保留，因置顶无独立分区）。
- 交互：单击打开；**右键/长按**弹菜单：置顶（切换）/标记已读（有未读时）。
  - 标记已读 = 本地 `readSeq` 水位线置顶（`localCache` 已有 markRead 能力，无后端调用）。
- 时间格式：今天 `HH:mm`；昨天 `昨天`；7 天内 `周X`；更早 `MM/dd`。

### 1.3 消息气泡 `MessageBubble`

```
群聊（对方）                                  群聊（自己）
                张三 14:32                            14:32
[头像36]  ┌──────────────┐                ┌──────────────┐  [头像36]
          │ 消息正文…      │                │ 消息正文…      │
          └──────────────┘                └──────────────┘
灰底 F2F3F5 · 圆角8/指向角4                浅蓝底 E8F0FF · 深色字 · 右对齐
```

- **双方都显示头像**（自己右侧）——原实现自己无头像，群聊中失去对齐锚。
- 连续消息（同人 5 分钟内）：隐藏头像与昵称行，头像位留空 36dp 保持缩进；指向角恢复 8dp。
- 群聊对方昵称行：`labelSmall` + `metaText`，时间跟在昵称后（`张三 14:32`）；私聊无昵称行。
- 气泡内边距：水平 12、垂直 8；文本 `bodyMedium`，最大宽 `bubbleMaxWidth`。
- **普通文本按内容收缩**：短消息不得因 Markdown 段落的 `fillMaxWidth` 被撑成长条；代码块/媒体可占用最大宽。
- 连续消息保留 4dp 视觉间隔，新消息组增大到约 6–8dp，避免多条气泡粘成整块色带。
- 已读回执：仅私聊自己最后一条已送达消息显示，气泡右下角外使用 11sp 低对比度文字。群聊不显示（无 per-user 已读，见 placeholders.md §5）。
- 时间分隔：间隔 >5 分钟插入居中 `labelSmall metaText` 纯文本（**去掉灰底胶囊**，飞书是裸文字）。
- 撤回：居中 `metaText` 裸文字"你/张三 撤回了一条消息"（原文案"消息已撤回"升级为带主语）。

**媒体消息形态**（MessageBodyRenderer）：

| 类型 | 形态 | 规格 |
|------|------|------|
| 图片/贴纸 | **贴边气泡**（无气泡内边距，媒体即气泡面） | fit-inside 240×320dp，最小边 120dp，圆角由气泡裁剪；无尺寸副标题 |
| 视频 | 深色 16:9 贴边卡 + 播放键 + 时长角标 | 固定深底(#20242C)；半透明黑(45%)圆形播放按钮 40dp + 白 PlayArrow；右下黑底(65%)白字时长；有服务端缩略图时自动替换底图；点击进画廊窗口内嵌播放器（应用内） |
| 语音 | **应用内播放卡片**（微信/飞书范式） | 播放/暂停键 18dp + 14 根 3dp 竖条波形（LCG 确定性高度，url 哈希种子）+ 时长；播放中已播条使用主色/容器前景色高亮、时长切换「当前/总长」；宽度随时长 64-220dp；播完自动复位。引擎：Desktop 用 compose-media-player 的 native 解码器（AAC/MP3/WAV 全格式，无 surface 纯音频）；Android 包装 MediaPlayer |
| 文件 | 扩展名彩色图标块卡片 | 40dp 圆角方块，扩展名映射色（pdf红/doc蓝/xls绿/ppt橙/压缩橙/图片紫/音视频…默认灰）+ 白色大写扩展名（≤3字符）；文件名 2 行截断 + 大小 metaText；点击走系统打开（文件类允许，媒体类不允许） |
| 回复 | 竖线引用卡 | 3dp 竖线（contentColor 40%）+ 引用者名 + 截断内容（65%），正文在引用块下方；两种气泡底色下都成立 |
| 位置/名片/合并转发 | 图标卡片（无平台渲染器 fallback） | InsertDriveFile 图标 + 标题 + 副标题，不再用 emoji |
- 交互：**右键/长按**气泡弹菜单：回复/编辑（自己+文本）/撤回（自己+2min）/转发。菜单用 `small` 圆角。

### 1.4 输入区（ChatPanel 底部）

```
┌────────────────────────────────────────────┐
│ ↩ 回复 张三：你好…（主色细字 + 取消）          │  ← 回复/编辑上下文条
│ 😊  B I S </>  🎙                ⊕          │  ← 工具行
│ ┌──────────────────────────────────┐       │
│ │ 所见即所得编辑区（min 3 行，富文本）      │  发送  │  ← 浅灰填充、圆角 8
│ └──────────────────────────────────┘       │
└────────────────────────────────────────────┘
  白底 + 顶部 divider；Enter 换行，Cmd/Ctrl+Enter 发送
```

- 工具行左侧：😊 表情（弹层：常用 emoji 8 列网格，插入光标处后回焦输入框）、
  **B/I/S/`</>` 格式键（WYSIWYG 直改样式**——选中文本立即变粗体/斜体，发送时编码为 markdown 语法；
  输入区为 `BasicRichTextEditor`（fork 源码，见 richeditor/FORK.md））、🎙 语音/键盘切换。
- 工具行右侧：⊕ 附件（弹层宫格：图片/视频/文件，40dp 主色容器块图标，替代旧 AlertDialog 文字菜单）。
- 弹层锚定按钮上方（PopupPositionProvider），ESC/外点关闭。
- **@ 补全**：输入 `@`+前缀 → 输入行上方内嵌补全层（候选=群成员/私聊好友，按名字/uid 过滤，排除自己，5 条）；
  选中写入 `@[名](mention://uid) ` 完整语法，输入框以 VisualTransformation **视觉折叠**为 `@名` 主色高亮块
  （原文不变，发送零转换）。@ 前须为行首/空白（邮箱误触防御）。
- **/ 指令**：行首 `/`+前缀 → 指令补全层（内置 /shrug /todo /code）；选中回填完整命令；
  发送时展开（/shrug msg → `msg ¯\_(ツ)_/¯`），未注册指令原样透传。
- 发送判定：所有新文本统一为 RICH_TEXT（普通文本是 Markdown 的自然子集）；
  Markdown 是唯一事实源，mentions/plainText 由 SDK 生成并在服务端重建。

### 1.5 导航栏（桌面专用，替代 M3 NavigationRail）

```
┌────┐
│[头像]│  32dp 用户头像（点击 → 设置 tab）
│────│
│ 💬 │  消息   选中：primary 色
│ 👥²│  通讯录 未选中：#646A73
│    │
│ ⚙  │  设置   底部对齐
└────┘
  宽 56dp，背景 #F2F3F5；选中项左侧 3dp 蓝色竖条；图标 22dp；无文字标签（悬停显示 tooltip——预留）
  好友申请红点：通讯录图标右上角徽标
```

- 通讯录 tab 徽标 = 待处理好友申请数（对齐 Android HomeScreen）。
- M3 NavigationRail 弃用原因：80dp 宽+文字标签+大触控，占中栏 27% 宽度且视觉笨重。

### 1.6 列表头 `ListHeader`

高 48dp：栏目标题（`titleMedium` SemiBold）左对齐，底部 `divider`，无 tonalElevation。
会话/通讯录标题栏不放搜索、建群和加好友；动作归属见 `product-information-architecture.md`。

### 1.7 徽标 `Badge`

pill（高 16dp，min 宽 16dp），`unreadBadge` 底白字 `labelMedium`，`99+` 封顶。数字 1-9 圆形，两位数拉伸为胶囊。

### 1.8 全局搜索 `GlobalSearchField` / `GlobalSearchScreen`

- Desktop 输入框位于 46dp 应用顶栏中央，最大宽 460dp，`Cmd/Ctrl+K` 聚焦。
- Android TopAppBar 只有全局搜索入口，结果页使用 44dp 搜索框。
- 分类固定：全部/消息/联系人/文件/服务；文件与服务没有索引时显示能力缺口空态。
- 用户结果打开资料：Desktop 为紧凑模态弹窗，Android 为全屏页；非好友显示“添加好友”，好友显示“发消息/发起群聊”。

## 2. 页面规格（桌面）

### 2.1 主窗口（三栏）

```
┌───────────────────────────────────────────────────┐
│ ● ● ●  TeamTalk       全局搜索 ⌘K             在线 │
├──┬────────────┬──────────────────────────────────┤
│导│ 会话         │ 张三                              │
│航│ ┌─────────┐ │                                  │
│栏│ │选中会话  │ │        消息区（白底）              │
│56│ │(浅蓝底)  │ │                                  │
│ │ │普通      │ │                                  │
│ │ │悬停(灰)  │ ├──────────────────────────────────┤
│ │ └─────────┘ │ 工具行 + 输入区                    │
└──┴────────────┴──────────────────────────────────┘
  窗口 1000×720、最小 880×600；中栏 300dp（surfaceVariant 底）；右栏内容 Surface
  空态按一级栏目区分：会话/通讯录/设置使用各自语义提示
  子页面：群详情/成员/邀请 → 聊天右侧 400dp 覆盖式检查器；用户资料 → 模态弹窗；其余 → 独立任务窗口
```

聊天检查器不参与三栏 Row 的尺寸分配：从聊天区右边缘滑入并覆盖右侧内容，聊天页、
消息滚动位置和输入状态保持不变；无遮罩，左侧仍可辨认当前上下文。根页右上角关闭，
内部页面用左上角返回，ESC 按“内部页 → 检查器 → 主内容页”逐级退出。

### 2.2 聊天面板

头部 48dp：私聊=对方名；群聊=群名 + 成员数（`（12）` metaText，需要成员数数据，暂缺则只群名）。
群名称只承担识别，不作为隐形入口；右侧齿轮按钮（`chat.settings`）打开群设置检查器。

### 2.3 登录窗口

居中卡片式：Logo + 产品名 → 用户名/密码输入（圆角 8）→ 登录（全宽主色，高 40）→ 底部「注册账号」文字链。整体宽 360dp，窗口 420×480 无装饰缩放。

### 2.4 通讯录

中栏列表：固定“新的朋友”入口 + 本地联系人过滤框（高 36 圆角 8）+ 拼音首字母分组 sticky 头 + 右侧索引条 + 联系人项。点击联系人打开居中的 UserProfile 模态弹窗，右栏保持原有上下文。应用级用户发现统一走顶部全局搜索。

### 2.5 设置（Me）

中栏：头部（头像 48 + 名 + username）+ 设置分组列表（编辑资料/修改密码/设备管理/黑名单/退出登录红字）+ 底部构建信息（`labelSmall metaText`）。

### 2.6 子窗口（独立 Window）

需要连续输入或选择的任务（建群/转发/安全设置…）使用宽 460×高按内容的独立窗口：

- macOS 原生红黄绿按钮与 48dp 应用工具栏融合，只保留一份标题；Windows/Linux 系统标题显示产品名，业务标题留在工具栏。
- 根任务依靠系统关闭按钮和 ESC，不显示移动端式返回箭头；窗口内进入下一层后才显示返回箭头。
- 标题左对齐，主操作在工具栏右侧；表单区使用 `lg` 边距。
- 全局搜索不弹独立窗口，在主窗口右栏呈现。

### 2.7 用户资料弹窗

Desktop UserProfile 是 400dp 宽的模态对象预览：标题/关闭 → 横向头像与身份信息 → 主动作 → 低频危险动作。弹窗不替换聊天区、不进入页面栈，ESC/点击关闭按钮退出；“发消息”直接进入会话，“发起群聊”打开已预选该用户的任务窗口。

## 3. 交互规范

| 交互 | 桌面 | Android |
|------|------|---------|
| 打开会话 | 单击 | 单击 |
| 列表项上下文菜单 | **右键** | 长按 |
| 气泡上下文菜单 | **右键** | 长按 |
| 发送消息 | Cmd/Ctrl+Enter，或点击发送 | 点击发送 |
| 文本换行 | Enter | Enter / IME 换行 |
| 关闭面板/子窗口 | ESC | 系统返回 |
| hover 态 | 有（列表/图标/菜单） | 无（API 兼容不触发） |

- 右键=长按：Compose Desktop 的 `combinedClickable.onLongClick` 在桌面由右键触发，两端共用一套代码。
- 焦点：窗口启动焦点登录输入框；打开会话焦点输入框；Cmd/Ctrl+K 聚焦全局搜索；ESC 逐级退出（面板→无）。
- 所有 `testTag` 必须保留（E2E 依赖），改版不改 tag 名。

## 4. Android 端差异

- 布局：底部 NavigationBar（3 tab）+ 全屏页面（NavHost），共享全部组件与令牌。
- 密度：列表项 72dp、头像 48dp（`Tk.dimens` 平台参数）。
- 输入：无工具行左对齐问题（空间足够保持水平排列）；Enter=换行，发送仅 IME 按钮。
- Android 与 Desktop 共用全局搜索数据、通讯录入口、用户资料业务动作和中性资料表面；承载容器与排版按平台分别实现，禁止把 Android 全屏页直接塞进 Desktop 内容栏。
