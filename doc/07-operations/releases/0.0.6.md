# TeamTalk 0.0.6

TeamTalk 0.0.6 是 0.0.5 之后的功能发行：好友私聊 1:1 音视频通话全链路（Android/Desktop，
内嵌 TURN/STUN NAT 兜底），发布通道改令牌判定，新增向前兼容双层兜底基建，并收敛内测
反馈的聊天体验修复。协议自 0.4 冻结至 0.5（1:1 通话契约）。
开发者预览定位与安装身份不变；普通升级保留服务端数据与客户端资料。

## 新功能：1:1 音视频通话（Android/Desktop）

- 好友私聊 1:1 语音/视频通话：聊天头部入口发起，来电全屏覆盖层（振铃/接听/拒接），
  通话中静音、免提切换，多摄像头设备可翻转摄像头（单摄设备自动隐藏入口）；
- 媒体面为 WebRTC P2P 直连，服务端只做信令路由与呼叫状态机；NAT 兜底由内嵌
  TURN/STUN 提供（纯 Kotlin 同进程实现，无独立中继进程），**首次部署自动生成凭据并
  默认启用**，需放行 UDP 3478 与 UDP 51000-51100；
- 通话记录（CALL_LOG）按普通消息语义进入会话：呼出/呼入、时长、未接原因；被叫离线
  时主叫收到「不可达」并自动落一条未接来电记录；
- 静默失败防线：本机无摄像头或系统拒绝授权时，通话不中断，顶部横幅与本地小窗明确
  提示「摄像头不可用」，视频自动降级为只收不发；
- 边界：iOS 通话入口与媒体引擎、群聊会议（SFU）、被叫离线实时唤醒（厂商通道）不在
  本期，见功能状态表。

## 新功能：发布与兼容基建

- 快照通道改发布令牌判定：同一快照版本每次发布生成随机令牌，客户端持不同令牌即
  推送更新——最后发布者赢，不依赖版本号单调，支持调试期同版本覆盖发布；
- 向前兼容双层兜底：更旧版本的客户端收到新版消息类型时，服务端按连接版本投影为
  占位形态（保留消息身份、显示「当前版本不支持此消息，升级客户端后可查看」），
  升级后自动还原为真实内容；客户端对未知通知与消息类型不再断连或报损坏；
- TURN 部署凭据并入 deployment.secrets 统一管理（回拉、原子保存、owner-only 权限），
  对外地址默认取站点 HTTP URL 主机，不再单独配置。

## 聊天体验修复（内测反馈）

- 消息搜索改相关性优先排序：精确匹配不再被更新的模糊命中淹没；
- 待办任务的日期/时间改日历与时钟选择组件（保留手填）；
- 文档列表项内嵌图片不再整块降级为「未建模」错误卡，按 Markdown 正常渲染；
- 「回到最新」胶囊触发距离放大约三倍，上滑一行不再立即出现；
- 长消息折叠阈值放大三倍，办公常态消息不再折叠；
- @提及胶囊改自绘圆角矩形（修复背景贴字与高度不齐），深色气泡内链接与 @提及改用
  浅蓝链接色；Windows 深色模式下窗格间白色竖条修复；iOS 系统深色模式跟随修复；
- 图片消息支持复制图片本体；桌面保存导出改原生面板；富文本文件块右键可保存；
- 文件点按行为按平台策略化：安装包/压缩包/可执行文件不再主动打开；
- 会话列表拖拽手柄物理跟随鼠标；桌面聊天工具窗口重设计（动作按会话类型收敛）；
- 管理台标识类文本（用户/设备/群/组织/消息检索）一键复制；
- Android 应用内升级闭环重做：下载完成即弹安装器，聊天中的 APK 直接触发安装。

## 修复

- 服务号台账条目序列化缺陷（管理台浏览器流程）；站点上传强制 HTTP/1.1 并加硬超时
  与网络重试；iOS 补齐聊天记录搜索平台接线；
- 通话引擎阶段性清理：Android 候选上送改用共享清洗规则、被叫侧信令先于引擎就绪的
  竞态缓存、双端死代码与重复装配收敛。

## 升级与数据影响

- **Desktop 壳 ABI 1→2（本版唯一需要用户动作的升级项）**：桌面壳补充了摄像头与麦克风
  的系统授权声明（macOS 通话授权框必需），**所有 0.0.5 桌面安装版必须重新下载首装包**，
  应用内更新会提示「请重新下载安装包」并提供下载入口；覆盖安装保留全部数据；
- 协议 0.5：服务端与客户端建议成套升级。服务器兼容窗口保持 `minimumProtocolMinor=0`，
  旧 0.0.5 客户端（协议 0.4）连接新服务端一切功能正常，仅无通话入口；通话需两端均为
  本版；新版本用户呼叫旧版本用户时，旧端收到「当前版本不支持此消息」占位来电记录，
  升级后自动还原；
- Android：安装序号随本版递增（versionCode 7），直接覆盖安装，保留账号、会话与草稿；
- 服务端：一条加列数据库迁移（发布令牌列），幂等可重入，经 epoch/dataset 预检保留
  全部数据；通话需在安全组放行 UDP 3478 与 UDP 51000-51100；
- 客户端本地数据库零 schema 变更，升级即用。

## 已知限制

- iOS 通话入口与媒体引擎不在本期；群聊会议（SFU）与通话保持/转移未提供；
- 被叫离线不实时唤醒（厂商透传通道与系统级通话界面属后续阶段）；
- 六家国产厂商推送与 iOS APNs 送达的真机验收沿用 0.0.5 状态；
- TURN relay 端口范围为默认 101 个并发分配，超大规模通话并发需调整范围；
- 详细边界见各平台文档与功能状态表。
