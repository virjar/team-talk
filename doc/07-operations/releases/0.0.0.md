# TeamTalk 0.0.0

首个开发者预览基线，面向小范围内测和私有化评估。项目尚未正式发布，对外不保证兼容，后续仍可能
有破坏性变更；内部普通升级开始保留既有资料，按协议兼容窗口维护短期兼容。

## 可以体验的能力

- Android 与 Desktop 共用 SDK 和核心交互，支持私聊、群聊、富文本及媒体附件。
- 消息回复、转发、编辑、撤回、已读水位、多设备同步、联系人和全文搜索。
- 单体服务端、管理后台、内嵌文件服务，以及可私有化配置的 HTTP/TCP 地址。
- Android 提供签名 APK；Desktop 提供 macOS 双架构、Windows、Linux 安装包及 Conveyor 更新站点。

## 安装与升级

本次将展示版本、内部构建计数和协议版本统一从零号开始记录。Android 安装 versionCode 为 1；
Desktop 安装 revision 为 1。早期开发包不属于此兼容基线；切换前应确认本地草稿、待发消息和需要
保留的资料。正式内测期间保留同一安装签名，避免不必要的卸载与本地资料丢失。

Android 当前需要手动下载并覆盖安装。macOS 最低为 14.0，Android 最低为 Android 8.0。
尚未完成正式 macOS 公证、Windows 受信任签名及所有平台的完整发布验收；安装时按下载页说明操作。
