# TeamTalk 0.0.0

TeamTalk 的第一版开发者预览，面向小型组织的真实沟通、轻量文档协作和私有化评估。开发者可以在
自己的服务器部署完整系统，也可以通过 SDK、CLI 和通知机器人接入现有工具。

本版是初始发行，不是稳定版承诺。预览期对外不保证版本兼容，未来仍可能有破坏性变更；从本版建立的
兼容基线开始，内部开发按协议窗口提供短期兼容，普通升级保留既有资料。

## 可以体验的能力

| 能力 | 本版可以做什么 |
|---|---|
| 账号与联系人 | 注册、登录、资料编辑、好友申请、私人备注、黑名单和登录设备管理 |
| 即时沟通 | 私聊、群聊、群成员与邀请管理；回复、转发、编辑、撤回、表情回应、收藏及消息搜索 |
| 多端与离线 | Android 与 Desktop 同步会话、已读和消息；普通草稿、待发队列与重连恢复；缓存内容离线读取 |
| 富文本与附件 | Markdown、代码块、图片、普通文件、语音和视频；媒体完整下载到本地后播放 |
| 轻量办公 | 组织通讯录与受管部门群；群共享文件的目录与版本；文档空间、授权、版本保存、冲突处理及聊天引用 |
| 部署与集成 | 单体服务端、管理后台、健康检查与日志；通知机器人、无头 SDK/CLI；统一 Gradle 构建与客户端分发 |

私有客户端可以使用独立的应用名称、安装标识和数据目录，与公版共存并固定连接自己的节点。没有域名
时可以使用 HTTP 站点与自签 TCP TLS 证书，客户端内嵌公共证书并验证服务器身份。

## 下载与安装

- 公版从 [TeamTalk 站点](https://im.virjar.com) 进入下载；私有版使用部署者提供的站点，安装前核对应用名称和目标节点。
- Android 8.0 及以上安装签名 APK；后续同身份、同签名升级通过手动下载覆盖安装完成。
- macOS 14.0 及以上按 Intel / Apple Silicon 选择对应 ZIP，解压后将应用放入 Applications。
- Windows 使用下载页提供的安装程序；Linux 提供 deb 与 tar.gz。完整安装与更新步骤以 Desktop 下载页为准。
- 自建节点从源码配置部署坐标，或使用发行附件中的 Server ZIP；准备与运维步骤见
  [私有化部署指南](https://github.com/virjar/team-talk/blob/v0.0.0/doc/01-getting-started/private-deployment.md)。

## 初始兼容基线

展示版本为 `0.0.0`，内部构建计数为 `0`，协议为 `0.0`，最低支持协议为 `0.0`。Android `versionCode`
和 Desktop Conveyor `revision` 均映射为 `1`；这些安装序号与协议能力分别管理。

这是一条全新的协议与数据基线，不提供从发行前试验数据到本版的原地迁移。旧测试包即使也显示
`0.0.0`，也不能据此视为本次发行的同一安装包；请使用本版下载入口，按新实例重新注册、登录。
切换前自行保存需要保留的本地草稿、待发消息和附件原件；旧开发包的安装序号较高时，需明确处理换装。

初始基线建立后，同一协议大版本只追加契约，已分发编号不回收；后续版本变更需说明升级影响。
本次经确认的测试实例重建和编号归零，不构成以后清空数据、覆盖既有版本或降低编号的授权。

## 已知限制

- Android 没有进程被系统回收后的 Push 唤醒，后台通知依赖进程存活和系统允许联网；重新打开应用后同步消息。
- 含内嵌图片或文件的未发送聊天草稿尚不支持跨进程恢复，请在本次使用中完成发送并保留原文件。
- 文档按版本保存并检测冲突，尚无逐字符协同；他人的修改、授权或目录变更需要刷新。
- 文档与文件搜索、文档评论、任务、日历、音视频通话和 iOS 客户端不在本版范围内。
- macOS 公证与 Windows 受信任签名尚未配置。跨平台出包不代表每种系统与架构都完成了完整实机验收，安装时按下载页说明操作。
- 完整备份恢复、长期存储治理和全部发布验收仍需完善。体验期间保留重要资料原件，不将本版作为不可替代资料的唯一存储。
