# TeamTalk 0.0.5

TeamTalk 0.0.5 是 0.0.4 之后的功能发行：iOS 正式接入为开发者预览受支持平台，移动端补齐
应用内拍摄与媒体体验，桌面新增聊天记录搜索，服务端新增姓名拼音搜索、服务号官方触达与
群文件自动归档，管理台提供离职资产交接与遥测事件检索，客户端遥测支持用户旅程上报。
协议自 0.3 冻结至 0.4（新增群文件移动命令与 iOS APNs 注册两个契约）。
开发者预览定位与安装身份不变；普通升级保留服务端数据与客户端资料。

## 新功能：iOS 平台（开发者预览）

- iOS 接入与 Android/Desktop 同一的 Kotlin SDK 与共享业务界面，原生实现 Network.framework
  TCP/TLS、URLSession HTTP、Keychain、SQLite、媒体、权限与相册/相机/录音链路；
- Apple Silicon 模拟器已通过真实账号全链路验收（登录认证、事件同步、心跳保活、消息收发、
  文档、群文件、媒体与录音）；安装渠道与验收边界独立维护，本版不发布 iOS 安装包，
  TestFlight 分发与 APNs 真机验收待后续批次。

## 新功能：拍摄与媒体

- 移动端附件面板多媒体入口收敛为「相册」与「拍摄」两个入口：相册图片进入正文、视频按
  附件消息发送；拍摄产物写账号缓存目录，不落入系统相册；
- 应用内相机：点按快门拍照、长按录像（60 秒上限自动停）、拍摄瞬间震动、按设备物理方向
  写入视频方向元数据、拍后预览确认（重拍/发送）；无摄像头设备给出提示不再崩溃；
- 画廊支持手动旋转与缩放；iOS 相册内嵌图片点击进入画廊。

## 新功能：聊天体验

- 消息编辑器回车交互对齐常见 IM：桌面端 Enter 直接发送，Cmd(macOS)/Ctrl(Windows)+Enter
  换行；移动端保持输入法习惯不变；
- 会话工具窗口新增「搜索聊天记录」：中心页提供聊天记录/图片及视频/文件/链接四类入口，
  分类页支持关键词、发送人与日期范围筛选，结果按时间倒序分组展示，点击跳转定位到原消息；
- 阅读历史时出现新消息或有人 @ 我时，提供「跳至未读」悬浮入口直达；远离最新视口提供
  「回到最新」；
- 长消息折叠后可在桌面弹窗/移动端页面查看全文；
- 桌面端聊天头部「···」提供会话工具窗口：发起群聊、本机清空聊天记录；桌面与 Android
  会话菜单支持「标为未读」。

## 新功能：服务端与办公协作

- 姓名拼音搜索：全拼与首字母拼音入库派生，用户搜索与聊天 @ 候选同源扩展；
- 服务号官方触达：新用户欢迎语按稳定身份自愈补发，管理台维护模板，管理员可全员广播
  （台账 + 幂等重推 + 启动续跑）；服务号回复持久恢复（同批发件箱、幂等补发）；
- 群文件：聊天中的非图片附件在消息提交时自动归档到「聊天文件」文件夹（与消息共享物理
  附件、引用独立计数，删除互不影响；失败不影响消息发送）；群文件支持移动到任意目录；
- 管理台离职资产面板：文档空间盘点、指纹确认与批量交接，群文件按群只读盘点。

## 新功能：遥测与排障

- 用户旅程上报：页面停留、关键用户动作与 INFO 级运行日志默认随遥测批次上传，组件内部
  细节仍保持诊断模式门控；用户反馈问题时，管理台可还原其操作路径；
- 崩溃遥测事件补全异常类型与堆栈帧；管理台日志页新增遥测事件检索，支持按事件类型、
  时间与账号过滤，逐条展开脱敏详情。

## 修复

- Android：APK 附件打开直达包安装管理器；
- iOS：首页双倍安全区留白、TCP 发送闪退、认证后帧上限未放宽的离线循环、Keychain 查询
  参数与 Xcode 增量陈旧链接、无摄像头设备相机崩溃；
- Windows：托盘菜单改用实时指针位置锚定；
- 会话列表贴顶时新消息重锚回顶，不再把新到会话顶出可视区；
- 新设备首次登录草稿假冲突与整段回放、聊天悬浮胶囊面板空白、块首 `<br>` 混排富文本、
  消息通知设置副标题写死小米推送；
- 安装器直链下载携带发布文件名，邀请落地页下载链接指向统一入口。

## 升级与数据影响

- 协议 0.4：服务端与客户端应成套升级。服务器兼容窗口保持 `minimumProtocolMinor=0`，
  旧 0.0.4 客户端（协议 0.3）仍可连接新服务端正常收发；群文件移动与 iOS APNs 注册等
  新能力需要新客户端。服务端升级经 epoch/dataset 预检，保留全部数据；
- Android：安装序号随本版递增（versionCode 6），直接覆盖安装，保留账号、会话与草稿；
- Desktop：按完整版本比较升级，覆盖安装保留数据；从 0.0.4 可经应用内更新升级；
- iOS：本版起为受支持平台，但不随本版分发安装包。

## 已知限制

- 六家国产厂商推送（小米/华为/荣耀/OPPO/vivo/魅族）代码就绪，均尚未完成真实送达的
  真机验收；
- iOS 的 APNs 送达、真机与 TestFlight 渠道未验收；
- Apple Silicon 原生媒体的实机矩阵与系统信任签名、公证边界未完全覆盖；
- 详细边界见各平台文档与功能状态表。
