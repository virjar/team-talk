# 业务验收场景目录

本目录描述产品必须持续满足的用户工作流。编号用于在测试代码、问题记录和发布验收中建立稳定引用；执行日期、通过数和截图位置不写在这里。

优先级含义：P0 是核心闭环，P1 是重要产品能力，P2 是增强能力或异常恢复。

## A. 身份与会话生命周期

| 编号 | 优先级 | 场景 | 关键结果 |
|---|---|---|---|
| ID-01 | P0 | 注册新账户 | 创建身份并进入主界面，输入校验明确 |
| ID-02 | P0 | 正确与错误密码登录 | 正确凭证建立会话，错误凭证不进入应用 |
| ID-03 | P0 | 重启后恢复会话 | 有效凭证静默恢复，过期或失效凭证回到登录态 |
| ID-04 | P0 | 退出登录 | 本地凭证、连接和用户态被清理 |
| ID-05 | P1 | 修改密码 | 旧密码校验，新密码生效，其他设备策略一致 |
| ID-06 | P1 | 设备管理与踢出 | 被踢设备断开并不能继续发送 |
| ID-07 | P0 | 协议版本不兼容 | 服务端明确拒绝后停止重连；Android 显示不可取消的升级弹窗并退出，普通网络故障不误触发 |

## H. 自动化通知

| 编号 | 优先级 | 场景 | 关键结果 |
|---|---|---|---|
| BOT-01 | P0 | 当前群成员创建通知机器人并通过 HTTP 投递 | 从群设置创建并只向创建者显示一次 `ttb_...` token；外部请求使用页面给出的完整入站 URL，Markdown 在当前群实时到达并标记机器人身份 |
| BOT-02 | P0 | 普通成员管理机器人所有权边界 | 普通成员可以创建、轮换和移除自己的机器人，但不能读取、轮换或移除其他成员的机器人；群主和群管理员可以移除成员创建的机器人但不能读取或轮换他人 token；系统下发机器人只由后台治理 |
| BOT-03 | P1 | 创建者轮换凭据或有权角色从群移除 | 轮换后旧 token 立即失效；创建者、群主或群管理员移除成员创建的机器人后，当前群授权和服务身份收回，原 URL/token 不能继续向该群发送 |
| BOT-04 | P1 | 幂等重试、正文边界与限速 | 相同正文和幂等键只产生一条消息；不同业务事件不复用 key；20,000 字符和 1–120 字符边界明确，单节点超过每 bot 120 次/分钟返回 429 |

## 场景落地规则

- 能在本地确定验证的边界，先加入单元或模块测试。
- 跨 RPC、数据库、文件或两个账户的场景，加入远程验收。
- 涉及窗口、动画、输入和平台能力的场景，加入真实客户端验收。
- 一个缺陷修复应落到最小稳定场景，而不是在本文追加一段事故描述。
- 当前未完成或仅部分完成的场景，在[功能状态](../10-reference/feature-status.md)中声明。
