# RPC IDL 化重构 — Kotlin interface + KSP 代码生成（精简版 gRPC）

## 目标形态

**IDL（手写，每 service 一个文件，`shared/.../rpc/def/`）：**
```kotlin
@RpcService("message")          // serviceId = 字符串（wire 直接传字符串）
interface MessageRpc {
    @RpcMethod(1)               // 可省略；省略时按声明顺序 1,2,3... 分配
    suspend fun getHistory(chatId: String, fromSeq: Long, limit: Int): List<Message>
    suspend fun revokeMessage(chatId: String, serverSeq: Long)
    suspend fun editMessage(msg: Message)                     // IProto 直传
    suspend fun searchMessages(chatId: String, keyword: String, limit: Int): List<Message>
}
```

**生成物（KSP 生成，每 service 一个文件，参数/编码/解码/Stub/Proxy 收敛于一体）：**
```kotlin
// build/generated/ksp/commonMain/.../rpc/gen/MessageRpcGrpc.kt
object MessageRpcContract {
    const val SERVICE = "message"
    const val M_GET_HISTORY = 1; const val M_REVOKE = 2; ...
    // 每方法参数编解码（唯一事实源，两侧共用）
    fun encodeGetHistory(chatId: String, fromSeq: Long, limit: Int): ByteArray
    fun decodeGetHistory(buf: PacketBuffer): GetHistoryParams
}

abstract class MessageRpcStub(val uid: String) : MessageRpc {
    // uid 收敛为成员——服务端实现类无 uid 参数，通过 this.uid 获取调用者
    suspend fun dispatch(methodId: Int, payload: ByteArray): ByteArray {
        // 生成：解码参数 → 调用本类方法 → 编码返回值
    }
}

class MessageRpcProxy(private val rpc: RpcInvoker) : MessageRpc {
    override suspend fun getHistory(chatId, fromSeq, limit): List<Message> =
        rpc.invoke(MessageRpcContract.SERVICE, M_GET_HISTORY, encode...) { decodeList... }
}
```

**服务端实现（改造现有 domain Service）：**
```kotlin
class MessageServiceImpl(uid: String, deps...) : MessageRpcStub(uid) {
    override suspend fun getHistory(chatId, fromSeq, limit) = ...  // 用 this.uid
}
```

## Phase 1 — 基础设施 + 试点（Device service，2 方法）

### 1.1 新增 `rpc-processor/` Gradle 模块（唯一新模块，KSP2）
- 依赖：`com.google.devtools.ksp:symbol-processing-api`（版本与 Kotlin 2.3.20 配对的 KSP 2.x）
- 职责：扫描 `@RpcService` interface → 校验（suspend/类型白名单/默认值禁用）→ 生成 4 类产物
- **类型白名单**：参数 String/Int/Long/Boolean/IProto 子类；返回同上 + Unit + List<IProto> + List<String>。超集 → KSP error（编译失败）
- **兼容性首验**：Phase 1 第一步验证 KSP2 + Kotlin 2.3.20 + KMP commonMain 可用；不可用则降级为 Gradle 生成任务（kotlinc 解析），形态不变
- libs.versions.toml 加 ksp 插件；shared 应用 `kspCommonMain`（生成代码进 commonMain 编译）

### 1.2 shared RPC 基础设施（`shared/.../rpc/`，手写）
- `RpcService.kt`：`@RpcService(name)` / `@RpcMethod(id)` 注解 + IDL 规范 KDoc
- `RpcInvoker`（改造现有）：`invoke(service: String, methodId: Int, payload)` —— ServiceId 枚举参数 → String
- `RpcRegistry`（生成汇总）：`Map<String, StubFactory>` / `Map<String, ProxyFactory>`，processor 生成注册代码

### 1.3 wire 变更（PROTOCOL_VERSION 1→2，一刀切）
- `InvokePayload.serviceId`：varInt → string
- `ServiceId` 枚举删除（GENERIC 扩展路由迁移为约定 service 名 "generic"）
- Frame.PROTOCOL_VERSION = 2；双端同仓同步；TestPeer/bot/FakeRpcInvoker 同步适配

### 1.4 试点全链路（Device：LIST/KICK）
- IDL `DeviceRpc` + 生成物跑通
- 服务端：`RpcDispatcher` 改造为 registry 派发（每请求构造 stub 薄壳，uid+domain 单例注入）；DeviceRouteHandler 删除
- 客户端：`DeviceRepository` 改用 `DeviceRpcProxy`
- 生成 round-trip 测试（processor 同时生成每方法参数样例 encode→decode 测试）

## Phase 2 — 全量迁移（7 个 service，逐个 commit）

每 service：写 IDL → 生成物 → domain Service 改为实现 Stub（方法去掉 uid 参数改用成员）→ 删 RouteHandler → Repository 换 Proxy → 删 RpcMethod.kt 对应枚举
- user / contact / chat / message / conversation / auth（+generic 约定路由）
- 全部手写 `encodePayload{}`/`withPayload{}` 从代码库消失
- **methodId 漂移防护**：生成 `XxxRpcContract` 常量表即 golden 文件（git diff 可见）；规则写入文档——新方法只追加末尾，中间插入必须显式 @RpcMethod
- TestPeer 改用 Proxy（顺带受益，删手写调用）；FakeRpcInvoker.calls 记录 (serviceName, methodId)

## 风险与对策

| 风险 | 对策 |
|------|------|
| KSP2/KMP 兼容 | Phase 1 首验；降级路径 = Gradle 生成任务（形态不变） |
| methodId 漂移 | 常量 golden 文件 + 文档规则 + 生成测试 |
| 生成器自身 bug | processor 同时生成全方法 round-trip 测试（生成物也被锁定） |
| wire 断旧客户端 | 接受（demo 我们控制，version bump 一刀切已确认） |

## Repository 层去留

保留——Repository 继续承担本地优先副作用（RPC 成功写 LocalCache、错误映射 AppError），内部实现从手写 encodePayload 换成 Proxy 调用。Proxy 是纯协议层，Repository 是 SDK 数据层，职责正交。
