# 管理后台（Admin Console）— React SPA + 单进程固定凭据 + 五页面 MVP

## 定稿架构

```
浏览器 ── React SPA（admin/，Vite+TS+antd5，构建产物入 server jar）
        └─ /api/admin/*（Ktor 同进程路由组，固定账号 env：ADMIN_USER/ADMIN_PASSWORD）
              ├─ 登录换 token（内存，12h 过期）→ Bearer 拦截
              └─ AdminService（domain/admin/）→ 复用各 Store/Repo/Service + Lucene
```

## 批次 1 — 封禁 enforcement（先修缺口，admin 的硬前提）

- `UserService.login` 检查 `status==2` → 拒绝（复用 CODE_AUTH_FAILED + reason"账号已被封禁"）
- `AuthService.handleRefresh`：validateAccessToken 后经 UserService 复查 status（refresh 路径现在完全不查用户状态）
- `TokenStore.revokeAllUserTokens(uid)` **恢复**（曾在 4c3a97e 以"零调用"删除——现在有调用了）
- `ClientRegistry.kickUser(uid)` 新增（遍历 getAgents 逐个 kick，与 kickDevice 对称）
- 测试：ban 后 login 拒 / refresh 拒 / token 全吊销验证

## 批次 2 — AdminService + REST API + 测试

**API 面**（`api/AdminRoutes.kt`，`fun Route.adminRoutes(adminService, config)`，沿用 FileRoutes 模式）：

| 端点 | 功能 |
|------|------|
| POST /api/admin/login | 固定凭据换 token（内存 map，12h） |
| GET /api/admin/overview | 在线数(ClientRegistry)/用户数/群数/今日事件量(sync_events 按日计数，口径=分发事件)/存储用量(walk RocksDB+file-store 目录)/最近错误(log 最近 fault 行) |
| GET /api/admin/users?query&page&size | 分页列表（UserRepository 新增 paged 查询：LIKE + count + limit(n,offset)） |
| GET /api/admin/users/{uid} | 详情聚合：user+devices+friends+groups+conversations |
| POST /api/admin/users/{uid}/ban | **三动作原子**：status=2 + revokeAllUserTokens + kickUser |
| POST /api/admin/users/{uid}/unban | status=1 |
| POST /api/admin/users/{uid}/kick-all | 仅踢线 |
| POST /api/admin/users/{uid}/reset-password | BCrypt 新密码 + 踢全部设备 |
| GET /api/admin/messages?chatId&senderUid&keyword&start&end&page&size | 全局消息检索（Lucene 已支持 sender/时间窗/offset——直接复用） |
| GET /api/admin/messages/{chatId}/{seq}/context | 上下文（getHistory 前后窗） |
| POST /api/admin/messages/{chatId}/{seq}/revoke | 管理员撤回（MessageService 拆 doRevoke 内部方法，admin 入口免权限检查，广播链路复用） |
| GET /api/admin/logs/server | 文件列表（logs/ + traces/，白名单目录） |
| GET /api/admin/logs/server/{name}?lines=300 | tail 读取（**路径穿越防护**：canonical path 必须在 logsDir 内） |
| GET /api/admin/logs/client?uid&deviceId | 客户端日志索引（遍历 client-logs 目录；ClientLogStore 新增 list/read） |
| GET /api/admin/logs/client/content?uid&deviceId&date | 内容查看 |
| GET /api/admin/groups?query&page&size | 群列表（ChatRepository 新增：chatType=2 join GroupChats，memberCount 子查询避免 N+1） |
| GET /api/admin/groups/{chatId} | 群详情+成员 |
| POST /api/admin/groups/{chatId}/dissolve / mute-all / unmute-all | dissolve 走 ChatService 权限参数化（admin 免 owner 检查） |

**配套**：CORS 安装（dev 源 localhost:5173）；DTO 用 kotlinx.serialization @Serializable；DI 注册 AdminService。

**测试**（AdminApiTest，testApplication 模式，参照 FileUploadAuthTest）：登录/错误凭据 401/无 token 401/用户分页/ban→login 拒→unban→login 通/消息搜索/日志路径穿越返回 400。

## 批次 3 — React 工程（admin/，与 android/desktop 平级的第四端）

```
admin/
├── package.json / vite.config.ts（dev proxy /api→8080）/ tsconfig.json
└── src/
    ├── api/client.ts        axios 实例 + token 注入 + 401 跳登录
    ├── App.tsx              antd Layout：Sider 菜单（Dashboard/用户/消息/日志/群）+ Header 登出
    ├── main.tsx / router
    └── pages/
        ├── Login.tsx         固定账号登录
        ├── Dashboard.tsx     统计卡片（在线/用户/群/事件/存储）+ 最近错误列表
        ├── Users.tsx         Table 分页搜索 + Drawer 详情（设备/好友/群/会话 tab）+ 操作（Popconfirm）
        ├── Messages.tsx      检索表单 + Table（高亮片段）+ Modal 上下文查看 + 撤回
        ├── Logs.tsx          Tab：服务端日志（文件列表→tail 查看）/ 客户端日志（uid/device 树→内容）
        └── Groups.tsx        Table + Drawer 成员 + 解散/全员禁言
```

技术选型：Vite 5 + React 18 + TypeScript + antd 5 + react-router-dom 6 + axios + dayjs。不引入状态管理库（内部工具，局部 state 够）。
